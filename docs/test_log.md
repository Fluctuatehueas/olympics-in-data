## 七、已修复的缺陷（记录在案）

| # | 问题 | 修复 |
|---|---|---|
| 1 | `itertuples()` 返回命名元组，用 `r["列名"]` 取列会抛 `TypeError: tuple indices must be integers` | 改为 `getattr(r, 列名)`，涉及 fig01 与 fig10 两处 |
| 2 | 分析洞察 1 初版结论方向写反（称近 76 年小项扩张最快，实测为代表团扩张更快） | 改为分阶段表述，并保留两条倍数作证据 |
| 3 | 洞察 5 初版用奖牌绝对总额计算前三名份额，被小项扩张稀释（得 5.1%） | 改为逐届内部份额取均值，修正为 27.0% |

## 八、已知限制（非缺陷）

1. **本机未安装 Python 运行时**，全部代码在隔离沙箱中执行；本机直接跑需先 `pip install -r requirements.txt`。
2. **Dashboard 依赖 CDN**：离线环境下 ECharts 无法加载，图表区会空白；静态 SVG 不受影响。
3. **静态图不使用 matplotlib**：为保证零字体依赖与矢量清晰度，图表由手写 SVG 生成，
   因此不支持复杂的交互式缩放，交互能力统一放在 Dashboard 里。
4. **未做单元测试框架**（pytest）：当前用断言脚本覆盖关键数字，
   对课程作业量级足够；若后续要长期维护，建议补 pytest。

## 九、测试结论

全部通过。代码满足「从原始 CSV 一键复现全部图表与分析结果」的要求。

# 数据质量与口径说明书

> 覆盖对象：`olympics_dataset.csv`（252,565 行 × 11 列，1896–2024 夏季奥运会）
> 本说明书中所有数字均由 `backend/src/cleaning.py` 与 `backend/src/quality_checks.py` 实测产出，可一键复现。

## 一、术语与粒度

**一行 = 一名运动员 × 一届奥运会 × 一个小项。** 团体项目的每位成员各占一行。
这是本数据集唯一的真实粒度，也是所有口径分歧的根源。

## 二、奖牌口径定义(Q1)

数据集里的 `Medal` 字段是**运动员行级**奖牌，不是**小项级**奖牌。本项目同时定义两套口径：

| 口径                          | 定义                             | 实现方式                            | 适用场景                       |
| --------------------------- | ------------------------------ | ------------------------------- | -------------------------- |
| **A · 运动员行口径**（athlete-row） | 每一行奖牌记录计 1 枚                   | `df[has_medal]` 直接计数            | 衡量"多少人次登上领奖台"、女性参与度、个人项目研究 |
| **B · 小项口径**（event-level）   | 同一"届次 × 小项 × 奖牌颜色 × NOC"只计 1 枚 | 去重键 `(Year, Event, Medal, NOC)` | 与官方奖牌榜对齐、跨国家横向比较           |

### 为什么去重键里要放 NOC

团体项目里同一个小项会同时产生多个国家的奖牌行（如 1904 年拔河的美国两支队伍同时拿牌），
也有跨国混合队（1900 年 `Denmark/Sweden`）。去重键加入 `NOC` 后：

- 同一国家在同一小项同一颜色只算 1 枚（吃掉团体项目的重复行）；
- 不同国家各自保留（并列奖牌、混合队各队都算到）。

> 注意：混合队在官方口径中通常归入 "Mixed Team (ZZX)"，本数据保留原始 NOC，
> 因此两德统一前后的对比、混合队届次的数字都不会与 IOC 官方完全吻合，这一点在正文中显式声明。

### 两套口径的差距规模

详见 `outputs/tables/quality_checks.md` 与 `docs/Task1/cleaning_verification.md`。核心事实：

| 口径        | 奖牌总数       | 说明                                           |
| --------- | ---------- | -------------------------------------------- |
| 运动员行口径（A） | **38,360** | 排除 1906 届后的奖牌行数（全量 38,818 含 1906 的 458 行）    |
| 小项口径（B）   | **17,901** | 去重后 Gold 5,816 / Silver 5,783 / Bronze 6,302 |

收缩 **53.3%**，即超过一半的奖牌行是团体项目成员的复制行。
最极端的例子是 QC2 中单组 117 行（同一届、同一小项、同一奖牌颜色）。

> 与官方对比的校准点：本项目小项口径下 2024 年金牌数为
> CHN 38、USA 37、JPN 20、NED 14。官方公布为 CHN 40、USA 40、NED 15。
> 差异来自去重键中的 `NOC`（混合队、跨国组合各计一次）与数据本身的缺失，
> 属于**已知且可解释**的偏差，正文凡与官方数字并列时均标注本口径。

## 三、体育大类归一（Q2）

原始 `Sport` 有 76 个取值，其中 89 行是逗号拼接的跨项写法（`Cycling Road, Triathlon` 等）。
归一策略：

1. **逗号拼接拆分**：以第一个成分为主项，完整拆分列表另存 `sport_all` 字段，供"按项统计"时展开；
2. **名称漂移合并**：
   - `Artistic Gymnastics` / `Rhythmic Gymnastics` / `Trampoline Gymnastics` → `Gymnastics`
   - `Cycling Road` / `Cycling Track` / `Cycling Mountain Bike` / `Cycling BMX Racing` / `Cycling BMX Freestyle` → `Cycling`
   - `Canoe Sprint` / `Canoe Slalom` → `Canoeing`
   - `Equestrian` → `Equestrianism`
   - `Artistic Swimming` → `Synchronized Swimming`
   - `3x3 Basketball` → `Basketball`
   - `Marathon Swimming` → `Swimming`
   - `Baseball/Softball` → 保留为独立项（两个子项合办，不做拆分）
3. **映射表**：`docs/Task1/sport_mapping.csv`，原始值 → 归一值（逗号拼接值按首项归一）。归一后共 **57** 个大类，零空值。

## 四、小项泛化处理（Q3）

2020 与 2024 两届共 30,013 行，其中 **6,488 行（21.62%）** 的 `Event` 是
`Men` / `Women` / `Men Team` / `Women Team` / `Mixed Team` / `Relay Only Athlete` 这类泛化值，
无法还原具体小项。泛化值 Top5：Men 1,634 / Women 1,539 / Men Team 1,425 / Women Team 1,317 / Mixed Team 416。

**处理策略（三选一，本项目采用 S2）：**

| 策略                | 做法                                                                                   | 优点   | 缺点                     |
| ----------------- | ------------------------------------------------------------------------------------ | ---- | ---------------------- |
| S1 · 剔除           | 删掉泛化行                                                                                | 干净   | 丢掉 21.6% 数据，且系统性地只丢近两届 |
| **S2 · 保留下沉（采用）** | 保留行，新增 `event_is_generic` 标记与 `event_resolved` 字段；所有"小项数"统计在泛化届次自动降维到"大类 × 性别"粒度并加标注 | 不丢数据 | 小项数量曲线在 2020 处不连续，须加脚注 |
| S3 · 外部补全         | 用官方赛果补出具体小项                                                                          | 最完整  | 引入外部数据，违背"仅用赛题数据可复现"   |

**采用 S2 的直接后果（必须全文一致）：**
凡展示"小项数量"的图表，2020/2024 两届只能用"大类 × 性别"组合数近似，
或以 `Event` 唯一值数作粗代理，图注必须写明。

## 五、特殊记录处理（Q5）

| 记录                | 规则                                                                                   | 实现                               |
| ----------------- | ------------------------------------------------------------------------------------ | -------------------------------- |
| **1906 届间奥运**     | 计入 `Year` 分布，但打 `is_official=False` 标记；"官方届次"统计默认排除                                  | `is_official = Year != 1906`     |
| **1956 双城**       | `City` 保留原值 `Melbourne`/`Stockholm`，不合并；`City` 分析时按 `Year` 聚合                        | 不做改写                             |
| **政体变迁**          | 新增 `noc_lineage` 字段，把 URS→EUN→RUS→ROC→AIN、FRG/GDR→GER、YUG→SCG→SRB 等映射到继承实体，用于长周期国家曲线 | `docs/Task1/noc_lineage.csv` |
| **抵制潮 1980/1984** | 不特殊处理，作为分析对象（NOC 数骤降本身就是证据）                                                          | —                                |
| **EOR 难民代表团**     | 保留 `EOR` 独立标识，不并入任何继承链                                                               | —                                |
| **Season**        | 恒为 Summer，作为冗余字段保留不动                                                                 | —                                |

> 关于 `noc_lineage`：只在"国家长周期曲线"类图表中使用，并在图注声明"含历史政体继承"；
> 其余涉及国家排名的图表一律使用原始 `NOC`，避免把苏联和俄罗斯混为一谈。

## 六、姓名与 ID（Q4）

`player_id` 平均每 ID 仅出现 1.07 次，同一运动员多次参赛会被拆成不同 ID；
`Name` 同时存在"一人多写法"和"多人一写法"（实测 498 个姓名跨度超过 50 年）。

**本项目处理决定：不做实体识别，只做风险声明。**

- 所有个体层面的分析（如"奖牌最多的人"）一律标注"基于 Name 字符串，可能因重名/改写失真"；
- 主结论不依赖个体粒度，全部落在**代表团 × 届次**这一稳健层级。

## 七、六项可复现质量检查

见 `backend/src/quality_checks.py`，输出 `outputs/tables/quality_checks.md`。**实测结果如下：**

| #   | 检查项               | 判定标准                  | 实测结果                                                       |
| --- | ----------------- | --------------------- | ---------------------------------------------------------- |
| QC1 | 奖牌颜色不均衡           | 差异可由早期无铜牌、并列奖牌、走跑夺冠解释 | 金 13,002 / 银 12,746 / 铜 13,070；金减银 **+256**，银减铜 **−324** ✅ |
| QC2 | 团体项目奖牌膨胀          | 应存在大量多于 1 行的组         | **5,080 组**，覆盖 **26,686 行**，单组最多 **117 行** ✅               |
| QC3 | 小项只发一种奖牌          | 应存在少数未发满三色的小项         | **163 个**（赛题文档称 34，判定标准不同，见下）                              |
| QC4 | Sport 口径漂移        | 应出现新旧名并存              | **7 组**并存，另 **89 行**逗号拼接 ✅                                 |
| QC5 | 2020 起 Event 泛化比例 | 应约两成                  | 30,013 行中 **6,488 行 = 21.62%** ✅                           |
| QC6 | 姓名歧义              | 应出现跨度超 50 年的同名        | **498 个**；player\_id 平均频次 **1.07** ✅                       |

### 两处与赛题文档的偏离（以实测为准）

1. **QC3 实测 163 个，赛题文档称 34 个。** 赛题的 34 大概率只统计了仅颁金牌的走跑情形；
   本项目判定为奖牌颜色种类少于三种，因此把早期只发金银、不发铜牌的届次也算进来。
   这是判定标准不同，不是数据错误，报告中引用时必须写明判定口径。
2. **QC5 实测 21.62%，赛题文档称 22 至 23 个百分点。** 差异来自泛化值集合的界定，
   本项目把 Open、Mixed 一并计入。两种界定都可接受，全文统一用 21.62%。

## 九、口径一致性自检

- 全文所有"奖牌数"默认指**小项口径**，凡使用运动员行口径处均显式标注；
- 所有涉及"小项数"的图表在 2020/2024 处加脚注；
- 1906 届默认排除，凡纳入处标注"含 1906"；
- 与 IOC 官方数字并列处，必须同时给出本口径的定义，避免误读。

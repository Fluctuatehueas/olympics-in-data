## 与赛题文档的偏差

赛题《2.2 数据快照》中若干数字与实测不完全一致，本项目一律以实测为准：

| 项目 | 赛题文档 | 实测 |
|---|---|---|
| player_id 平均出现次数 | 1.1 次 | 252,565 / 235,903 ≈ **1.07 次** |
| 唯一运动员姓名 | 约 130,000 | **129,992** ✓ |
| Sport 取值 | 76 种 | **76** ✓ |
| Event 取值 | 1,041 种 | **1,041** ✓ |
| NOC | 234 | **234** ✓ |

> 结论：文档中的关键结构性数字（行数、奖牌分布、唯一值数）均准确，仅 player_id 平均频次一处表述偏大，不影响分析。
